SentinelForge-AI-Suite





⚡ SentinelForge AI Suite
Advanced AI Engineering & Developer Sandbox

A Streamlit-based developer sandbox that combines four AI engineering concepts into one interactive dashboard.


✨ Features










🎙️ 1. Voice Agent Stream
- Simulated real-time voice processing.
- STT, LLM and TTS pipeline demonstration.
- Audio chunk buffering and latency controls.













🛡️ 2. Security Firewall Proxy
- Prompt injection detection.
- Credential exposure checks.
- Risk scoring and payload sanitization.













💻 3. AST Code Review Agent
- Detects eval() usage.
- Identifies basic SQL injection patterns.
- Categorizes findings by severity.













🚀 4. QLoRA Training Console
- Base model configuration.
- LoRA rank and batch-size controls.
- Simulated training loss visualization.

⚙️ Installation
1. Clone the repository
git clone https://github.com/<your-username>/SentinelForge-AI-Suite.git
cd SentinelForge-AI-Suite


2. Install dependencies
pip install streamlit numpy pandas pydantic


3. Run the application
streamlit run app.py


🧭 Dashboard Modules
Module	Function
Voice Agent	Audio pipeline simulation

AST Reviewer	Code vulnerability checks
QLoRA Console	Fine-tuning simulation


⚠️ Important Notes
This project is an interactive prototype. The voice pipeline, security checks, code analysis, and QLoRA training are currently simulated or heuristic-based, not production integrations.
